# @iocalc/conformance

Conformance helpers for IOCALC-compatible sandbox implementations.

## Includes

- Capability and manifest checks.
- Read/command/resolve/report/log/match-history conformance flows.
- Guardian fixtures for safe gameplay, poisoned issues, workflow-token probes,
  and model-originated code/secret tool escalation.
- Governance ledger and boundary evidence checks.
- Browser-play conformance options for fixed UI selectors.

## Boundary

Conformance checks verify sandbox behavior. They do not certify wallet,
financial, production, account, session, arbitrary URL fetch, code execution, or
secret-handling capabilities.
